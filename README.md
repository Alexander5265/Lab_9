# Юркин Александр ИТС-1 Лабораторная №9

# Задание 1.

### Текст задачи.

Реализовать приложение из ЛАБОРАТОРНОЙ РАБОТЫ №6 ЗАДАНИЯ 2 и 3 (Перегрузка операций) в
виде WPF-приложения с графическим интерфейсом. Все требования к функционалу сохраняются.
Предусмотреть обработку возможных ошибок при работе программы.
Максимально за лабораторную работу можно получить 6 баллов.
Коды, оформленные с нарушением код-стайла, или реализованные с помощью LINQ не принимаются!

### Алгоритм решения.

1. Создан WPF-проект в Rider на платформе .NET.
2. Реализован класс Triangle для хранения сторон треугольника.
3. Добавлены методы проверки существования треугольника и вычисления площади.
4. Реализована перегрузка операторов:
   - оператор "-" для вычисления площади;
   - операторы ">" и "<" для сравнения площадей;
5. Разработан графический интерфейс WPF:
   - поля ввода сторон треугольников;
   - кнопка вычисления;
   - поле вывода результатов.
6. Добавана обработка ошибок:
   - проверка корректности ввода;
   - проверка положительных значений сторон;
   - вывод сообщений об ошибках.
7. Выполнено тестирование работы приложения.
